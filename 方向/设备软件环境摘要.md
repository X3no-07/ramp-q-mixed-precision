# Jetson设备软件环境摘要

以下是2026-10-16首次连板记录中的历史观测，不代表当前设备在线状态。

| 项目 | 记录 |
|---|---|
| 目标设备 | Jetson Orin NX 8GB研究环境 |
| 系统 | Ubuntu 20.04.6 LTS，aarch64，内核5.10.104-tegra |
| PyTorch | NVIDIA发行版2.0.0+nv23.05；板端曾报告2.0.0+nv23.5 |
| torchvision | 0.15.1 |
| TensorRT | 8.5.2.2 |
| Python | 3.8.10 |
| NumPy | 1.24.4 |
| 功耗配置 | 当时查询为15W，模式ID 2；该ID仅对应当时所用配置 |
| 初步验证 | FP32/FP16矩阵乘法smoke通过；固定单图PyTorch推理通过 |

原设备排障文档包含连接地址和操作记录，未随发布快照上传。临时登录脚本、私钥及凭据也被排除。该摘要只保留软件和实验环境信息。

后续TensorRT构建、实际精度、逐目标命中和数值护栏须按各自报告理解，不能用初步smoke替代完整部署验收。PC端Gate1与板端环境不同，见[工程入口](../工程/README.md)。
