# 证据与结论边界

本表依据截至 2026-10-19 的本地保存记录。它不是板子当前在线状态检查。

## 两个阶段分别说明什么

| 层次 | 已有证据 | 可作出的判断 | 尚不能推出 |
|---|---|---|---|
| Gate 0 模拟 | RUOD-R、YOLO11n、PyTorch Q/DQ W8A8、固定划分及双向模块干预 | 当前模拟设置下存在目标级破坏与恢复信号 | 原生 INT8 具备同样效果或性能优势 |
| 原生工程 | 六配置构建、反序列化、88 个源卷积格式映射及固定图执行 | 存在可执行的原生引擎路径 | 数值正确、检测精度通过、机制在实机复现 |
| 固定图 FP16 | 两个预测，末次复跑主/辅助数组逐位一致 | 本固定图对照可重复 | 持续硬件稳定、数据集准确率、FPS |
| 固定图量化 | 五配置均零检测，输出有限 | 需优先处理明显数值异常 | G1 归因被否定、量化机制不存在 |
| 整数计算证据 | q_only_G1 的 6 个请求 INT8 卷积具备命名整数 tactic | 该配置的既定 tactic 检查完成 | 所有配置的严格整数算术证明已完整 |

## 当前六配置

| 配置 | INT8 / FP16 卷积 | 命名整数 tactic / 请求 INT8 | 固定图预测数 |
|---|---:|---:|---:|
| fp16_control | 0 / 88 | 不适用 | 2 |
| q_all | 88 / 0 | 81 / 88 | 0 |
| r_only_G1 | 82 / 6 | 75 / 82 | 0 |
| r_only_G1_G5 | 74 / 14 | 67 / 74 | 0 |
| r_only_G1_G2 | 77 / 11 | 70 / 77 | 0 |
| q_only_G1 | 6 / 82 | 6 / 6 | 0 |

固定图为 Selection `000020.jpg`，conf=0.25。图中标签仅有一个海参目标，FP16 匹配成功；第二个扇贝预测没有对应的本图标注，不能写成“两个标注目标均检出”。各量化配置中该标注目标均未匹配。这是单图描述，不能推广为数据集全漏检。

q_only_G1 的保存输出中，PyTorch CPU 和 ORT CPU 最高类别分数分别约 0.657063、0.657379，原生 TensorRT 为 0.00313583。差异已存在于 NMS 前。CPU FP32 与板端 FP16、融合和后端实现等因素尚未隔离，因此仍无法唯一归因。

四个配置各有 7 个深度卷积没有暴露 tactic 名。NVTX 与 CUDA 关联能够确定它们实际运行了哪个内核；函数名称含 INT8 或 IMMA 不等于执行算术指令证明。缺少这种证明也不等于已证明算术错误。

## 不能更改的历史事实

原始 PyTorch/ORT 全模型数值护栏失败；中间张量强制对齐仅用于诊断，不能替代独立运行通过。构建失败、30 分钟超时和后续更长预算成功都需保留。没有运行 150 张原生数据集评估，也没有形成实机精度、恢复、因果或性能通过结论。
