# Data and artifact availability

This edition contains source code, existing tests, example configurations, split membership identifiers, chronological reports 00–91, stage navigation, and a selected result summary.

Raw images and annotations, dataset downloads, external pretrained checkpoints, trained weights, TensorRT engines, prediction arrays, complete run directories, large publication bundles, local caches, and device authentication records are excluded from the Git tree. They remain in the original local research collection.

Links to local-only evidence in the reading copies resolve to this page. Run identifiers, metrics, negative results, and scientific limitations remain in the reports. Such references do not mean that complete evidence is distributed with this edition. The detailed device-access record is represented by a hardware/software summary without connection details.

## Provenance and file identity

[SOURCE_FILES.jsonl](../export/SOURCE_FILES.jsonl) records the source digests and current exported paths and digests. Source identifiers refer to pre-export local records. The English translation, portable configurations, and updated navigation have different file digests.

Historical manifests may refer to excluded members or original source versions. Do not apply an old whole-delivery integrity audit to this filtered edition. Validate the export manifest first, then determine whether the required historical members and original versions are available.

## Split membership

The ordered 350-image Selection and 150-image Holdout memberships are retained. Tracked lists use paths relative to the RUOD-R dataset root. The configuration tool generates ignored absolute-path lists for the local machine.

Path normalization changes list-file hashes. It does not replace frozen contracts or authorize a new use of independent holdout data.
