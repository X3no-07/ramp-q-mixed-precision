# Gate 0 Holdout：G1+G5双向验证摘要

> 当前结论：**G1+G5在独立holdout上通过候选自身的预注册门槛，形成方向一致的双向信号。最终Gate判断仍需完成G1单模块holdout对照。**

## 数据范围

- Holdout图片：150张。
- FP32原本命中：722个目标。
- 全W8A8新增漏检：46个目标。
- 配置在查看holdout模块结果前已经锁定为G1+G5。

## 双向结果

| 指标 | Selection | Holdout |
|---|---:|---:|
| 破坏侧与全W8A8漏检重合 | 100/119（84.03%） | 31/46（67.39%） |
| 恢复侧救回 | 100/119（84.03%） | 43/46（93.48%） |
| 附带漏检 | 8 | 5 |
| 稳定目标保持率 | 99.45% | 99.26% |
| 净救回 | +92 | +38 |
| 双向同目标 | 83/119（69.75%） | 29/46（63.04%） |

Holdout中有31个全W8A8新增漏检在G1+G5单独量化时消失；恢复G1+G5后救回43个，其中29个属于同一批双向一致目标。另有2个目标只有破坏侧成立，14个只有恢复侧成立。

## 候选自身门槛

| Holdout冻结门槛 | 结果 | 判断 |
|---|---:|---|
| 救回率不低于15% | 93.48% | 通过 |
| 稳定目标保持率不低于98% | 99.26% | 通过 |
| 净救回为正 | +38 | 通过 |
| 至少1个双向同目标 | 29 | 通过 |
| 不由单张图片或单一类别完全主导 | 见下 | 通过 |

## 集中性检查

- 43个救回目标分布在25张图片和7个类别。
- 单张图片最多贡献5个救回目标，占11.63%。
- 最大类别为类别0，共12个，占27.91%。
- 29个双向同目标分布在19张图片和7个类别；单张图片最大占10.34%，单类别最大占31.03%。

结果没有被单张图片或单一类别完全主导。但holdout只有46个新增漏检，比例仍存在抽样波动，不能把93.48%视为普遍真实救回率。

## 当前判断边界

- G1+G5在Selection与holdout上均表现为净救回为正、稳定保持率高、存在大量同目标双向一致样本，因此“该候选具有可复现信号”得到支持。
- 还不能回答G5相对G1的增量是否在holdout复现；必须继续运行预注册的 `q_only:G1` 与 `r_only:G1` 对照。
- 本结果使用PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson速度、能耗证据。
