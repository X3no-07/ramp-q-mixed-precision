# 数值结果与下载

本仓库代码树保存研究方向、报告、源码、配置、测试、日志和审计元数据。模型权重、ONNX/TensorRT引擎、NPY/NPZ/MAT数值输出和大日志位于同一私有仓库的 [snapshot-2026-10-23 Release](https://github.com/X3no-07/ramp-q-mixed-precision/releases/tag/snapshot-2026-10-23)。私有附件需要有仓库访问权限。

- [Release附件大小与SHA256](release_assets.json)
- [纳入文件及原始SHA、附件成员映射](included_files.jsonl)
- [未上传文件及原因](excluded_files.jsonl)
- [整理统计](preparation_summary.json)
- [报告链接转换及缺件列表](report_link_rewrites.json)

原始数据集、真实图片/标注、封闭Holdout、临时SSH接入材料、第三方运行时分发包及不透明旧ZIP未上传。既有manifest原样保留，其中可能引用未上传成员；它们是历史证据，不能把本过滤快照当作原整包已通过校验。

可先登录官方GitHub CLI，然后在仓库根目录执行：

```powershell
gh auth login
python 工程/发布清单/restore_results.py --root . --download
```

脚本校验附件和每个结果文件SHA，安全恢复其原相对目录；不会下载原始数据或覆盖内容不同的已有文件。默认只恢复Release映射的派生成果，不访问Holdout。若只需文档与代码，无需下载数值附件。
