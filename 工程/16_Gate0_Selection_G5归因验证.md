# Gate 0 Selection：G5双向隔离摘要

> 当前结论：**G5有小幅正收益，但没有通过候选门槛，暂列低优先级。** 它的破坏侧排名第二，但恢复侧和双向同目标证据较弱。

## 干预定义

- `q_only:G5`：只有G5使用模拟W8A8，其余模块保持FP32。
- `r_only:G5`：全模型使用模拟W8A8，只有G5恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G5结果 |
|---|---:|
| `q_only:G5`造成的漏检 | 21 |
| 上述漏检中属于全W8A8新增漏检 | 19 |
| `r_only:G5`救回的全W8A8新增漏检 | 16 |
| 救回率 | 13.45% |
| 同时满足“G5量化会丢、G5恢复会回”的目标 | 2 |
| 双向同目标比例（2/119） | 1.68% |
| G5量化会丢、但恢复G5仍未回来 | 17 |
| G5恢复能救回、但单独量化G5未弄丢 | 14 |
| 恢复G5造成的附带漏检 | 6 |
| 稳定目标保持率 | 99.59% |
| 净救回（16-6） | +10 |
| G5卷积MAC占比代理 | 12.03% |

## 对暂定门槛的判断

| 暂定门槛 | G5 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 13.45%，16个 | 不通过 |
| 稳定目标保持率至少98% | 99.59% | 通过 |
| 净救回为正 | +10 | 通过 |
| 恢复模块MAC占比不超过25% | 12.03% | 通过 |

## 正确解释

G5单独量化的破坏侧信号在G1之后排名第二，但恢复G5只救回16个目标，且只有2个目标同时满足两侧干预条件。它可能参与模块交互，但目前不能作为独立的强因果模块。相比G2和G4，G5的附带漏检较少、净收益为正，因此保留为低优先级组合候选。

## 证据边界与下一步

- 本结果来自PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson实测。
- 当前只使用Selection，holdout没有用于推理或模块选择。
- G5不作为当前单模块强候选，但后续可以进入与G1的双模块组合备选池。
- 下一步是只运行 `q_only:G6`。
