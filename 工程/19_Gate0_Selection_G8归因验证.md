# Gate 0 Selection：G8双向隔离摘要

> 当前结论：**G8双向证据不成立，暂时淘汰。** 救回规模、净收益和同目标一致性均不足。

## 干预定义

- `q_only:G8`：只有G8使用模拟W8A8，其余模块保持FP32。
- `r_only:G8`：全模型使用模拟W8A8，只有G8恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G8结果 |
|---|---:|
| `q_only:G8`造成的漏检 | 10 |
| 上述漏检中属于全W8A8新增漏检 | 6 |
| `r_only:G8`救回的全W8A8新增漏检 | 7 |
| 救回率 | 5.88% |
| 同时满足“G8量化会丢、G8恢复会回”的目标 | 0 |
| 双向同目标比例 | 0.00% |
| G8量化会丢、但恢复G8仍未回来 | 6 |
| G8恢复能救回、但单独量化G8未弄丢 | 7 |
| 恢复G8造成的附带漏检 | 3 |
| 稳定目标保持率 | 99.79% |
| 净救回（7-3） | +4 |
| G8卷积MAC占比代理 | 9.25% |

## 对暂定门槛的判断

| 暂定门槛 | G8 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 5.88%，7个 | 不通过 |
| 稳定目标保持率至少98% | 99.79% | 通过 |
| 净救回为正 | +4 | 通过但很弱 |
| 恢复模块MAC占比不超过25% | 9.25% | 通过 |

## 正确解释

G8只救回7个目标，且没有任何目标同时满足两侧干预条件。单独量化G8造成的6个全W8A8漏检目标，在恢复G8时一个都没有回来。因此没有形成可靠的G8模块级证据。
