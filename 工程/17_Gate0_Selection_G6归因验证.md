# Gate 0 Selection：G6双向隔离摘要

> 当前结论：**G6双向证据不成立，暂时淘汰。** 恢复G6的救回与附带漏检数量相同，净收益为零。

## 干预定义

- `q_only:G6`：只有G6使用模拟W8A8，其余模块保持FP32。
- `r_only:G6`：全模型使用模拟W8A8，只有G6恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 对暂定门槛的判断

| 暂定门槛 | G6 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 2.52%，3个 | 不通过 |
| 稳定目标保持率至少98% | 99.79% | 通过 |
| 净救回为正 | 0 | 不通过 |
| 恢复模块MAC占比不超过25% | 12.86% | 通过 |

## 正确解释

G6只救回3个目标，同时又造成3个稳定目标漏检，而且双向同目标数量为0。恢复侧和破坏侧涉及的不是同一批目标，因此没有形成可靠的G6模块级证据。
