# Gate 0 Selection：G7双向隔离摘要

> 当前结论：**G7双向证据不成立，暂时淘汰。** 尽管G7是P3小目标分支，但实验不支持优先将其恢复FP32。

## 干预定义

- `q_only:G7`：只有G7使用模拟W8A8，其余模块保持FP32。
- `r_only:G7`：全模型使用模拟W8A8，只有G7恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G7结果 |
|---|---:|
| `q_only:G7`造成的漏检 | 16 |
| 上述漏检中属于全W8A8新增漏检 | 13 |
| `r_only:G7`救回的全W8A8新增漏检 | 10 |
| 救回率 | 8.40% |
| 同时满足“G7量化会丢、G7恢复会回”的目标 | 0 |
| 双向同目标比例 | 0.00% |
| G7量化会丢、但恢复G7仍未回来 | 13 |
| G7恢复能救回、但单独量化G7未弄丢 | 10 |
| 恢复G7造成的附带漏检 | 6 |
| 稳定目标保持率 | 99.59% |
| 净救回（10-6） | +4 |
| G7卷积MAC占比代理 | 17.78% |

## 对暂定门槛的判断

| 暂定门槛 | G7 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 8.40%，10个 | 不通过 |
| 稳定目标保持率至少98% | 99.59% | 通过 |
| 净救回为正 | +4 | 通过但很弱 |
| 恢复模块MAC占比不超过25% | 17.78% | 通过 |

## 正确解释

G7是结构上与小目标最直接相关的P3检测分支，但结构直觉没有得到本次隔离实验支持。单独量化G7导致的13个全W8A8漏检目标，在恢复G7时一个都没有回来；恢复G7救回的10个又都不是破坏侧目标。因此不能把“它是小目标分支”当作保留FP32的充分依据。

## 证据边界与下一步

- 本结果来自PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson实测。
- 当前只使用Selection，holdout没有用于推理或模块选择。
- G7暂时淘汰，保留全部原始结果。
- 下一步是只运行 `q_only:G8`，完成最后一个模块的破坏侧扫描。
