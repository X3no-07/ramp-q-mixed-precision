# Gate 0 Selection：G2双向隔离摘要

> 当前结论：**G2双向证据不成立，暂时不是值得保留FP32的候选模块。** 这是Selection上的淘汰判断，不是最终Gate结论。

## 干预定义

- `q_only:G2`：只有G2使用模拟W8A8，其余模块保持FP32。
- `r_only:G2`：全模型使用模拟W8A8，只有G2恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G2结果 |
|---|---:|
| `q_only:G2`造成的漏检 | 9 |
| 上述漏检中属于全W8A8新增漏检 | 8 |
| `r_only:G2`救回的全W8A8新增漏检 | 16 |
| 救回率 | 13.45% |
| 同时满足“G2量化会丢、G2恢复会回”的目标 | 1 |
| 双向同目标比例（1/119） | 0.84% |
| G2量化会丢、但恢复G2仍未回来 | 7 |
| G2恢复能救回、但单独量化G2未弄丢 | 15 |
| 恢复G2造成的附带漏检 | 19 |
| 稳定目标保持率 | 98.69% |
| 净救回（16-19） | -3 |
| G2卷积MAC占比代理 | 12.65% |

## 对暂定门槛的判断

| 暂定门槛 | G2 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 13.45%，16个 | 不通过 |
| 稳定目标保持率至少98% | 98.69% | 通过 |
| 净救回为正 | -3 | 不通过 |
| 恢复模块MAC占比不超过25% | 12.65% | 通过 |

## 正确解释

G2只有1个目标同时满足两侧干预条件，说明“G2量化造成消失”和“恢复G2产生救回”基本不是同一批目标。恢复G2虽然偶然救回16个目标，但同时损失19个原本稳定目标，净收益为负，因此不能把总体救回数解释为可靠的G2因果证据。

## 证据边界与下一步
