# Gate 0 Selection：G3双向隔离摘要

> 当前结论：**G3属于边缘但不通过，暂列低优先级候选。** 它有小幅净收益，但救回数量和双向同目标证据不足。

## 干预定义

- `q_only:G3`：只有G3使用模拟W8A8，其余模块保持FP32。
- `r_only:G3`：全模型使用模拟W8A8，只有G3恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G3结果 |
|---|---:|
| `q_only:G3`造成的漏检 | 11 |
| 上述漏检中属于全W8A8新增漏检 | 9 |
| `r_only:G3`救回的全W8A8新增漏检 | 19 |
| 救回率 | 15.97% |
| 同时满足“G3量化会丢、G3恢复会回”的目标 | 2 |
| 双向同目标比例（2/119） | 1.68% |
| G3量化会丢、但恢复G3仍未回来 | 7 |
| G3恢复能救回、但单独量化G3未弄丢 | 17 |
| 恢复G3造成的附带漏检 | 12 |
| 稳定目标保持率 | 99.17% |
| 净救回（19-12） | +7 |
| G3卷积MAC占比代理 | 11.82% |

## 对暂定门槛的判断

| 暂定门槛 | G3 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 15.97%，19个 | 不通过（少1个） |
| 稳定目标保持率至少98% | 99.17% | 通过 |
| 净救回为正 | +7 | 通过 |
| 恢复模块MAC占比不超过25% | 11.82% | 通过 |

## 正确解释

G3恢复有轻微正收益，但只有2个目标同时满足两侧干预条件，说明G3单独量化造成的目标消失与恢复G3救回的目标基本不是同一批。当前证据更像模块交互或检测阈值附近的变化，尚不足以支持稳定的G3模块级机制。

## 证据边界与下一步

- 本结果来自PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson实测。
- 当前只使用Selection，holdout没有用于推理或模块选择。
- G3不进入当前强候选，但保留为低优先级模块，待G1-G8全部完成后统一排名。
- 下一步是只运行 `q_only:G4`。
