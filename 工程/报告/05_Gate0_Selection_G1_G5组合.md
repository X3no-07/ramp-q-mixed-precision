# Gate 0 Selection：G1+G5双向组合摘要

> 当前结论：**G1+G5通过全部预注册的增量门槛，可以进入候选池。** 这只是Selection结论，仍须完成预注册备组合G1+G3，之后才能锁定唯一holdout候选。

## 干预定义

- `q_only:G1+G5`：只有G1和G5使用模拟W8A8，其余模块保持FP32。
- `r_only:G1+G5`：全模型使用模拟W8A8，只有G1和G5恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G1单模块 | G1+G5 | 增量 |
|---|---:|---:|---:|
| 破坏侧与全W8A8漏检重合 | 88 | 100 | +12 |
| 救回数 | 94 | 100 | +6 |
| 救回率 | 78.99% | 84.03% | +5.04个百分点 |
| 附带漏检 | 13 | 8 | -5 |
| 稳定目标保持率 | 99.10% | 99.45% | +0.35个百分点 |
| 净救回 | +81 | +92 | +11 |
| 双向同目标 | 69 | 83 | +14 |
| MAC占比代理 | 10.32% | 22.35% | +12.03个百分点 |

G1+G5中，100个目标在破坏侧属于全W8A8新增漏检，100个目标在恢复侧被救回，其中83个是同一批目标。另有17个目标只有破坏侧成立，17个只有恢复侧成立。

## 预注册门槛核对

| 冻结门槛 | G1+G5结果 | 判断 |
|---|---:|---|
| 救回数至少99 | 100 | 通过 |
| 净救回至少+86 | +92 | 通过 |
| 稳定目标保持率至少98% | 99.45% | 通过 |
| 双向同目标至少69 | 83 | 通过 |
| MAC占比不超过25% | 22.35% | 通过 |

## 正确解释

与只恢复G1相比，额外恢复G5增加了6个救回目标，同时减少了5个附带漏检，使净救回提高11个；双向一致目标增加14个。代价是FP32计算量代理从10.32%上升到22.35%。因此G1+G5在Selection上是有效的精度—成本候选，但尚不能直接宣布为最终方案。

## 证据边界与下一步

- 本结果来自PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson实测。
- 当前只使用Selection，holdout没有用于推理或组合选择。
- 必须按预注册继续完整运行备组合 `q_only:G1+G3` 和 `r_only:G1+G3`，不能因主组合已经通过而提前停止。
