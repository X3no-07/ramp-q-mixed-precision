# Gate 0 Selection：G4双向隔离摘要

> 当前结论：**G4双向证据不成立，暂时不是值得保留FP32的候选模块。**

## 干预定义

- `q_only:G4`：只有G4使用模拟W8A8，其余模块保持FP32。
- `r_only:G4`：全模型使用模拟W8A8，只有G4恢复FP32。
- Selection中FP32原本命中1571个目标，全W8A8新增漏检119个。

## 总体结果

| 指标 | G4结果 |
|---|---:|
| `q_only:G4`造成的漏检 | 7 |
| 上述漏检中属于全W8A8新增漏检 | 6 |
| `r_only:G4`救回的全W8A8新增漏检 | 12 |
| 救回率 | 10.08% |
| 同时满足“G4量化会丢、G4恢复会回”的目标 | 0 |
| 双向同目标比例 | 0.00% |
| G4量化会丢、但恢复G4仍未回来 | 6 |
| G4恢复能救回、但单独量化G4未弄丢 | 12 |
| 恢复G4造成的附带漏检 | 10 |
| 稳定目标保持率 | 99.31% |
| 净救回（12-10） | +2 |
| G4卷积MAC占比代理 | 13.29% |

## 对暂定门槛的判断

| 暂定门槛 | G4 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 10.08%，12个 | 不通过 |
| 稳定目标保持率至少98% | 99.31% | 通过 |
| 净救回为正 | +2 | 通过但很弱 |
| 恢复模块MAC占比不超过25% | 13.29% | 通过 |

## 正确解释

G4没有任何目标同时满足两侧干预条件。也就是说，单独量化G4造成消失的6个全W8A8漏检目标，在恢复G4时一个都没有重新出现；恢复G4救回的12个则都不是单独量化G4时丢失的目标。因此不能把这12个总体救回解释为稳定的G4模块级因果证据。

## 证据边界与下一步
