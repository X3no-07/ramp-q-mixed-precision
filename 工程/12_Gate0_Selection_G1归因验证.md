# Gate 0 Selection：G1双向隔离摘要

> 当前结论：**G1出现强双向信号，但只是在Selection上的候选证据，不能提前打开holdout，也不能据此结束G2-G8比较。**

## 干预定义

- `q_only:G1`：只有G1使用模拟W8A8，其余模块保持FP32，用于测试G1是否足以造成目标消失。
- `r_only:G1`：全模型使用模拟W8A8，只有G1恢复FP32，用于测试G1是否能够救回目标。
- 匹配对象限定为Selection中FP32原本命中的1571个目标；全W8A8新增漏检为119个。

## 总体结果

| 指标 | G1结果 |
|---|---:|
| `q_only:G1`造成的漏检 | 100 |
| 上述漏检中属于全W8A8新增漏检 | 88 |
| `r_only:G1`救回的全W8A8新增漏检 | 94 |
| 同时满足“G1量化会丢、G1恢复会回”的目标 | 69 |
| 双向同目标比例（69/119） | 57.98% |
| G1量化会丢、但恢复G1仍未回来 | 19 |
| G1恢复能救回、但单独量化G1未弄丢 | 25 |
| 恢复G1造成的附带漏检 | 13 |
| 稳定目标保持率 | 99.10% |
| 净救回（94-13） | 81 |
| G1卷积MAC占比代理 | 10.32% |

## 对暂定门槛的判断

| 暂定门槛 | G1 | Selection判断 |
|---|---:|---|
| 救回率至少15%，且至少20个 | 78.99%，94个 | 通过 |
| 稳定目标保持率至少98% | 99.10% | 通过 |
| 净救回为正 | +81 | 通过 |
| 恢复模块MAC占比不超过25% | 10.32% | 通过 |

## 正确解释

69个目标提供最直接的双向一致证据：只量化G1时它们消失，而从全W8A8恢复G1时它们重新出现。这说明G1很可能是重要敏感区域。

但结果不是完美一一对应：19个目标只有破坏侧成立，25个目标只有恢复侧成立。这提示网络中仍存在模块交互、阈值抖动或一对一匹配竞争，不能把所有119个漏检都归因于G1。

## 证据边界与下一步

- 本结果来自PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson实测。
- 当前只使用Selection，holdout没有用于推理或模块选择。
- 不能因为G1结果强就直接打开holdout；必须先用相同规则扫描G2-G8，才能判断G1是否真正排名靠前。
- 下一步是只运行 `q_only:G2`，不同时运行其他组。
