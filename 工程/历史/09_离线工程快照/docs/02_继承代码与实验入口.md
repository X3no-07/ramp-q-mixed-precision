# 继承代码与实验入口

## 新版已实现

`src/stage2.py` 的四个入口为本版新增、已执行的离线工具：`verify`、`status`、`compare`、`plan`。配置用相对路径，保存输出在本目录内即可读取。检查失败会停止，不回退到“忽略缺失数据”。

## 保留的历史代码

`legacy/07/` 中原目录层级和文件字节保持不变，来源可在 `config/source_manifest.json` 逐项查询。SSH 授权脚本不在快照中。以下是关键入口，而不是要求本次重新执行的命令。

| 文件（均相对 legacy/07） | 用途 | 实际运行还需要 |
|---|---|---|
| src/gate0.py | 目标匹配与模拟量化相关逻辑 | 原模型、数据及 Python 深度学习依赖 |
| src/run_gate0_selection.py | 模拟模块干预入口 | 原划分、权重、校准和已冻结实验协议 |
| scripts/prepare_gate05_precision_candidates.py | 构造既有候选图 | 原 ONNX/量化/模块映射资产 |
| scripts/jetson_build_precision_candidate.py | 板端候选引擎构建 | Jetson TensorRT、对应冻结 bundle 和监护 |
| scripts/jetson_monitored_build.py | 原构建监护 | 板端环境、任务目录和明确预算 |
| scripts/audit_gate05_precision_candidate.py | 实际精度格式与 tactic 审计 | 原 inspector、spec、模块映射、ONNX |

## 有意保留的未实现部分

实际 CUDA 输入回读、严格配对的浮点/融合对照、数值首次分歧定位的新诊断流程，以及新数据集验收/性能协议尚待落实。历史目录中的局部 probe 代码存在，不代表上述研究问题已经解决。08 文稿将这些内容统一标为待实施或待冻结。

## 文件边界

09 包含保存数组与选取的报告，但不包含 engine、完整 Nsight trace 或训练数据。`evidence/07/.../manifest.json` 若列出更多原始文件，只用于保留历史来源，不代表这些文件全部随本目录复制。验证当前交付文件使用根目录的 `config/source_manifest.json`。

当需要查看更深层证据时，回到 07 相应目录，以原生回执为准。09 的文件完整性通过仅说明所选副本与来源一致；原生数值失败和严格整数计算证据缺口继续有效。
