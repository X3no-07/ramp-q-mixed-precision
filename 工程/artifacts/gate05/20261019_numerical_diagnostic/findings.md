# 同一张固定图的数值差异因果诊断

日期：2026-10-19。仅使用原来的 `000020.jpg`、原权重、原校准尺度与原始 Q/DQ ONNX。**原 `LOCAL_QDQ_PREFLIGHT_FAILED` 仍然成立。** 未进行数据集评估、板端推理或阈值修改。

已知的 88 组权重 Q/DQ 一致、同输入激活量化一致检查没有重复运行。本次控制卷积边界，检查小浮点差异如何进入后续量化。

| 本次数值干预 | 最终框最大绝对差 | 最终分数最大绝对差 | 后续 Conv 输入的量化值不同元素数 |
|---|---:|---:|---:|
| 原实现重复对照 | 96.570465 | 0.0729592 | 3,325,427 |
| 仅把第一个 Conv 输出替换为 ORT 的对应输出 | 86.511719 | 0.0786303 | 3,283,078 |
| 把全部 88 个 Conv 输出逐一替换为 ORT 的对应输出 | 0 | 0.000000130615 | 1 |

这是对原计算过程的**诊断干预**，不是新的可部署量化配置。最后一行的数值接近不能记为原模型通过。

已验证：

- 当前 PyTorch 无干预输出与旧保存输出逐元素完全一致；添加中间输出的 ORT 与旧 ORT 保存输出也完全一致，排除了本轮观察手段改变主输出。
- 只替换第一层 Conv 输出，就消除了第二层输入原来的三个量化分档差异。例如同一输入位置的归一化值原来分别为 `0.50000244` 与 `0.49999937`，跨过 0.5 边界后量化结果相差一个完整量化步长。最终输出仍不接近，说明后续计算也会继续产生差异，不能把整网问题归结为第一层。
- 控制全部卷积输出后，88 处量化前浮点输入的最大差仅 `3.8146973e-6`，原来的 3,325,427 个量化分档差异只剩一个。框解码结果完全一致，分数最大差约 `1.31e-7`。在这张图上，这支持“反复出现的小浮点计算差异经量化分档放大并传播”的解释。
- 剩余一个分档差异位于 `model.23.cv3.0.0.1.conv`，索引 `[0,48,54,38]`。量化前数值仅差 `2.3841858e-7`：PyTorch 为 `2.8653330803`，ORT 为 `2.8653333187`。除以同一尺度 `0.0744242370` 后分别为 `38.5` 与 `38.5000038147`，量化后变成 `2.8281209469` 与 `2.9025452137`。其上游是同一个已控制输出的 Conv，接着 PyTorch SiLU / ONNX Sigmoid+Mul。该例直接表明，卷积以外的等价浮点激活实现也能在分档边界触发完整的一步差异。

仍未证明：

- 没有找到权重、零点、尺度或量化公式的具体实现错误；本轮证据不能排除所有其他图转换问题。
- 仅诊断一个固定样本，不能推断其他图像、平台或精度配置的误差大小、检测精度和救回效果。
- 控制全部卷积输出会主动阻断差异传播，不能作为正常独立运行模型的通过证据。
- 原始独立 PyTorch 与 ORT Q/DQ 全模型仍同时超过原始框和分数容差；本次未修改或替代这个结论。
