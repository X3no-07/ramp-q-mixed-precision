# Gate 0 Selection：G1+G3双向组合摘要

> 当前结论：**G1+G3未通过预注册增量门槛，不能替代G1单模块，也不进入holdout。**

## 总体结果

| 指标 | G1单模块 | G1+G3 | 增量 |
|---|---:|---:|---:|
| 破坏侧与全W8A8漏检重合 | 88 | 88 | 0 |
| 救回数 | 94 | 90 | -4 |
| 救回率 | 78.99% | 75.63% | -3.36个百分点 |
| 附带漏检 | 13 | 9 | -4 |
| 稳定目标保持率 | 99.10% | 99.38% | +0.28个百分点 |
| 净救回 | +81 | +81 | 0 |
| 双向同目标 | 69 | 67 | -2 |
| MAC占比代理 | 10.32% | 22.14% | +11.82个百分点 |

G1+G3中，88个目标在破坏侧属于全W8A8新增漏检，90个目标在恢复侧被救回，其中67个是同一批目标。另有21个目标只有破坏侧成立，23个只有恢复侧成立。

## 预注册门槛核对

| 冻结门槛 | G1+G3结果 | 判断 |
|---|---:|---|
| 救回数至少99 | 90 | 不通过 |
| 净救回至少+86 | +81 | 不通过 |
| 稳定目标保持率至少98% | 99.38% | 通过 |
| 双向同目标至少69 | 67 | 不通过 |
| MAC占比不超过25% | 22.14% | 通过 |

## 正确解释

额外恢复G3减少了4个附带漏检，但也少救回4个全W8A8新增漏检，因此净救回没有超过G1，双向一致性反而下降，同时FP32计算量代理增加11.82个百分点。G1+G3不具有足够增量价值。

## 证据边界

- 本结果来自Selection和PyTorch Q/DQ模拟W8A8，不是TensorRT INT8或Jetson实测。
- holdout没有用于本组合推理或候选选择。
