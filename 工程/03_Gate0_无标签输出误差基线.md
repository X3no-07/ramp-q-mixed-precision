# Gate 0 无标签输出重建误差基线

> 结果：无标签输出误差方法在全部同预算组合中选出`G1+G2`；在预注册的未运行随机池中选出`G1+G2`。本步骤没有读取标签，也没有运行或读取三个随机组合的检测结果。

## 1. 冻结条件

- 校准图片：64张，名单SHA-256：`02caf7d8888b72a8ac884eb95aeb76ae9c9dd984baf3b1714a379faf2eaa7069`。
- 模型SHA-256：`62aa0728fba4cf9443a154d7db0b1b771a7373c1d302c6c24e3f2a9ac98061af`。
- 设备：`cuda:0`。
- 配置：分别比较FP32与`q_only:G1`至`q_only:G8`的NMS前检测输出。
- 没有读取目标标签；没有读取尚未产生的随机对照结果。

## 3. 同预算组合选择

- 全部满足预算的两模块组合：选出`G1+G2`，分数和为6.99851109e-03，MAC占比22.97%。
- 仅预注册未运行随机池：选出`G1+G2`，分数和为6.99851109e-03，MAC占比22.97%。
- 与RAMP-Q候选`G1+G5`是否碰撞：否。

预注册中的‘同一预算池’可能被狭义理解为未运行随机池。为避免选择性报告，这里同时公开狭义结果与包含候选在内的全组合诊断，后续不得只保留更有利的一项。

## 4. 如何解释

输出重建误差只回答‘量化哪个模块会让模型原始输出变化较大’，不直接回答哪些真实目标漏检或被救回。它是传统的无标签代理基线，不是检测效果结论。

## 证据边界

结果来自RUOD-R的64张校准图和PyTorch Q/DQ模拟W8A8。没有使用目标标签，但仍共享已用于量化校准的图片；它不是独立测试集结果，也不代表TensorRT、Jetson、延迟或能耗表现。
